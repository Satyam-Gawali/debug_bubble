Acceptance criteria:
- Filter matching (`FilterMatcher` & `DebugLogFilter.matches`):
  - Exact level match (`levels`; empty set matches all levels, not a minimum threshold).
  - Exact tag match (`tag`; case-sensitive, null matches all).
  - Search query (`query`): trimmed, case-insensitive substring matching against `message`, `tag`, `subTag`, `error.type`, and `error.message`.
  - Stack trace, metadata, and JSON are strictly excluded from query matching (D-22).
  - All present criteria combine with AND logic.
- JSON exporter (`JsonExporter` & `controller.exportJson`):
  - Emits versioned JSON conforming strictly to Schema v1 (DATA_MODELS.md §8).
  - Fields: `schemaVersion` (1), `exportedAt` (UTC ISO-8601), `packageVersion`, `buildMode` ("debug" or "profile"), `redaction` (enabled, valuePatternCount), `limits` (echoes configured caps), `totalEntries`, `exportedEntries`, `droppedCount` (controller-wide capacity drops, D-23), `filter`, and `entries` (oldest → newest).
  - Disposed controller returns valid zero-entry schema v1 document (L-8, DATA_MODELS.md §8).
  - Inert release controller returns empty string (DATA_MODELS.md §8).
- Plain-text exporter (`TextExporter` & `controller.exportText`):
  - Formats single entry blocks per DATA_MODELS.md §9 (header with timestamp, uppercase level, tag/subTag, sequence id, `(truncated)` suffix; message; error; metadata; json; stack trace; absent fields omitted).
  - Multi-entry export starts with `debug_bubble log export — N entries (M older entries dropped)`, followed by blank-line-separated blocks in oldest → newest order.
  - Enforces internal clipboard character budget cap of 500,000 characters (D-26). If the text exceeds the budget, oldest entries in the selection are omitted and the header states the total older entries dropped.
  - Disposed controller returns valid zero-entry plain text document (`debug_bubble log export — 0 entries (0 older entries dropped)`).
  - Inert release controller returns empty string.
- Controller wiring (`DebugBubbleController`):
  - `query(filter)` returns matching entries in oldest → newest order without mutating the store; returns empty list if inactive or disposed.
  - `exportJson({filter})` and `exportText({filter})` wire to `JsonExporter` and `TextExporter`.
- Public API integrity:
  - Preserves exactly the ten documented symbols in `lib/debug_bubble.dart`.
  - Zero external dependencies; Flutter SDK only.

  - Focused tests for JSON Schema v1 structure, filtered export, build modes, zero-entry document, and sentinel secret non-retention under `test/unit/export/`.
  - Focused tests for plain-text formatting, ordering, capacity dropped counter, character budget cap omission, zero-entry document, and sentinel secret non-retention under `test/unit/export/`.

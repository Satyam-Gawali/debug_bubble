# T3.4 — Logs & Errors Lists
Status: Implemented (Pending Consolidated Verification)
Phase / depends on: P3 / T3.3, T2.7
Scope: Implementation of live log lists, debounced search, exact severity filter chips, live counts, auto-scroll, and empty states (`lib/src/ui/log_list.dart`) per UI_UX_SPEC.md §3 and DATA_MODELS.md §4.
Prerequisites: T3.3 (dashboard shell), T2.7 (filter matching).
Expected file changes: `lib/src/ui/log_list.dart`, `lib/src/ui/dashboard.dart`, `doc/tasks/T3.4-log-list.md`, `test/widget/log_list_widget_test.dart`
Acceptance criteria:
- Renders live log entries using controller APIs (`entries`, `query`).
- Separate views for Logs (all levels) and Errors (pre-filtered to `error` and `critical`).
- Search field with 250 ms debounce matching `DebugLogFilter.query` semantics (message, tag, subTag, error type/message; case-insensitive substring).
- Severity level chips with exact-level multi-select semantics.
- Errors tab offers only `error` and `critical` chips.
- "Reset filters" action appears whenever query or level filters are active.
- Counts line shows "Showing X of Y" and appends dropped count when `droppedCount > 0`.
- Empty states for empty buffer ("No logs yet") and filter miss ("No matches for current filters").
- Auto-scrolls to latest entry at bottom; scrolling up shows "Jump to latest" button.
- Row renders level badge (color + text), local timestamp (`HH:mm:ss.SSS`), tag chip, 2-line message, error indicator, truncation badge, sequence ID.
- Tapping a row invokes `onSelectEntry`.
Relevant tests: `test/widget/log_list_widget_test.dart`

# T2.4 — Bounded Payload Conversion
Status: Done
Phase / depends on: P2 / T2.1, T2.3
Scope: Implementation of bounded payload traversal and entry sanitization (`PayloadSanitizer`, `EntrySanitizer`) with retention priority, shared budgets, cycles, depth/node/item caps, and surrogate-safe truncation per DATA_MODELS.md §6–§7 and SECURITY_PERFORMANCE.md §4.
Prerequisites: T2.1 (data models), T2.3 (redaction engine).
Expected file changes: lib/src/core/sanitize/payload_sanitizer.dart, lib/src/core/sanitize/entry_sanitizer.dart, test/unit/sanitize/sanitizer_test.dart
Acceptance criteria:
- Bounded payload traversal (PayloadSanitizer):
  - Traversal depth capped at 8 (depth > 8 yields `[MaxDepth]`).
  - Node budget capped at 2,000 nodes (yields `[Truncated]`).
  - Collection item cap at 200 items (Maps retain 200 items + `[truncated]` marker; Iterables retain 200 items + `[N more items omitted]`).
  - String values in payload capped at 2,000 chars.
  - Map keys capped at 200 chars.
  - Cycle detection via ancestor path identity check (yields `[Circular]`).
  - Hostile inputs handled safely without throwing: throwing `toString()` yields `[Unprintable: Type]`; hostile iterables throwing mid-iteration yield `[IterationError: Type]`.
  - Non-finite numbers (`NaN`, `Infinity`, `-Infinity`) safely converted to strings.
  - DateTimes converted to UTC ISO-8601 strings.
  - Truncated flag set whenever any cut, omission, or marker occurs.
- Entry budgeting and retention priority (EntrySanitizer):
  - Enforces combined `maxEntryChars` budget (default 40,000 chars).
  - Priority order strictly honored: tag/subTag -> message -> error -> stack trace -> metadata -> json.
  - Metadata and JSON share `maxPayloadLength` (default 32,000 chars) with metadata converted first.
  - Truncation marker `…[truncated]` (12 chars) appended when strings exceed budget.
  - Truncation is UTF-16 surrogate-pair safe (never splits a surrogate pair).
  - Raw objects are not retained (mutating source inputs after sanitization has zero effect on sanitized output).
  - Redaction integration: masks sensitive map keys (skipping subtrees) and value patterns across message, error, stack, tag, and string values.

# T3.1 — UI Hosting & Navigation Foundation
Status: Implemented (Pending Consolidated Verification)
Phase / depends on: P3 / G2 (Phase 2 completion)
Scope: Implementation of the root UI hosting container (`DebugBubble`) embedded via `MaterialApp.builder` above the host `Navigator`, with own Material/Theme/Overlay hierarchy, and safe system back-button interception.
Prerequisites: G2 (all Phase 2 tasks complete and verified).
Expected file changes: `lib/src/ui/debug_bubble.dart`, `doc/tasks/T3.1-ui-hosting-foundation.md`, `test/widget/debug_bubble_widget_test.dart`
Acceptance criteria:
- Renders host `child` at the base of the widget Stack.
- When controller is inert, disposed, or absent (`controller == null` or `!controller.isActive` or `BuildMode.isRelease`), renders only `child` with zero UI overlay overhead.
- Embeds own `Material`, `Theme`, and nested `Overlay` above the host content when dashboard is active.
- Intercepts system back (`WidgetsBindingObserver.didPopRoute`) when dashboard is open, closing the dashboard without popping host routes.
- When dashboard is closed, system back passes through completely unmodified to the host application.
- Responds reactively to controller notifications (`openDashboard`, `closeDashboard`, `dispose`).
Relevant tests: `test/widget/debug_bubble_widget_test.dart`

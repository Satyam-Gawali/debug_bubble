Status: Implemented (Pending Consolidated Verification)

Acceptance criteria:
- Opened by selecting an entry in the log or error list, contained within dashboard layer without touching host Navigator.
- Displays sections only when data exists: header (level, UTC timestamp, tag/subTag, id, truncation warning), full message, error (type, message), stack trace, metadata, JSON.
- Pretty-prints structured JSON and metadata on demand.
- Monospace styling and horizontal scrolling for stack traces, metadata, and JSON payloads.
- Selectable text (`SelectableText`) for message, error, stack trace, and JSON.
- Copy actions for plain text (`TextExporter.formatEntry`) and JSON payload with user feedback.
- Back button returns to the list view; system back also closes the detail view first (D-27).

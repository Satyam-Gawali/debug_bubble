# T3.7 — Theme, Accessibility & Responsive Behavior
Status: Implemented (Pending Consolidated Verification)
Phase / depends on: P3 / T3.3
Scope: Central theme resolver, high-contrast severity color palette, accessibility semantics, reduced-motion awareness, large text scale support, and keyboard insets handling per UI_UX_SPEC.md §7, §8.
Prerequisites: T3.3 (dashboard shell).
Expected file changes: `lib/src/ui/theme.dart`, `lib/src/ui/dashboard.dart`, `lib/src/ui/log_list.dart`, `lib/src/ui/entry_detail.dart`, `doc/tasks/T3.7-theme-accessibility.md`, `test/widget/theme_widget_test.dart`
Acceptance criteria:
- `DebugDashboardTheme.resolveTheme` respects `ThemeMode.system` (following platform brightness), `ThemeMode.light`, and `ThemeMode.dark`.
- Dashboard theme does not inherit unwanted styling from the host application.
- High-contrast color palette for all severity levels meeting WCAG contrast guidelines in both dark and light modes.
- Supports custom per-level color overrides via `DebugBubbleTheme.levelColors`.
- Honors reduced motion settings (`MediaQuery.disableAnimationsOf(context)`), omitting transitions.
- Fully responsive under large text scaling (tested with `TextScaler.linear(2.0)`) without layout overflow errors.
- Dynamic keyboard insets handling using `MediaQuery.viewInsetsOf(context)` so lists and search inputs remain accessible.
- Accessible touch targets $\ge 48$ logical pixels for all action buttons and interactive controls.
- Accessible semantics labels and live regions for outcome banners.
Relevant tests: `test/widget/theme_widget_test.dart`

# T3.3 — Dashboard Shell & Overlay Layer
Status: Implemented (Pending Consolidated Verification)
Phase / depends on: P3 / T3.1, T3.2
Scope: Implementation of the full-screen dashboard container and top bar shell per UI_UX_SPEC.md §2.

Expected file changes: `lib/src/ui/dashboard.dart`, `doc/tasks/T3.3-dashboard-shell.md`, `test/widget/dashboard_widget_test.dart`
Acceptance criteria:
- Full-screen overlay layer respecting safe area.
- Draws its own `Material`, independent `Theme` (matching `ThemeMode.system/light/dark`), and a nested `Overlay` for menus and selection toolbars.
- Top bar contains title, statistics counter (entries / errors), and close button.
- Tapping the close button invokes `controller.closeDashboard()`.
- Tab bar with three tabs: **Logs · Errors · Info** (D-10).
- Errors tab displays error badge reflecting active error count.
- Animated transition (fade/slide) that is skipped or instant when `MediaQuery.disableAnimationsOf(context)` is true.
- Keyboard insets dynamically adjust the view.

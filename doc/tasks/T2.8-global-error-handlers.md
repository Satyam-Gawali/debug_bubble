Acceptance criteria:
- Configuration and opt-in (E-1, D-08):
  - `captureUncaughtErrors` defaults to `false`.
  - Only active controllers with `captureUncaughtErrors: true` register with `ErrorHookRegistry`.
  - Inactive controllers (disabled or release mode) never touch handlers.
- Single wrapper pair & shared registry (E-2, L-9):
  - Exactly one wrapper pair installed globally across all controllers.
  - Remembers previous `FlutterError.onError` and `PlatformDispatcher.instance.onError` (which may be null).
  - Multiple controllers share the wrappers without stacking; each registered controller receives uncaught errors.
- FlutterError wrapper (E-3, E-9):
  - Forwards uncaught error details to all registered sinks with level `DebugLogLevel.error`, `tag: 'FlutterError'`, `isUncaught: true`.
  - Internal capture is wrapped in try/catch to isolate failures (NFR-03).
  - Always invokes previous `FlutterError.onError` outside try/catch so host behavior and exceptions remain unchanged.
- PlatformDispatcher wrapper (E-4, E-9):
  - Forwards uncaught platform errors to all registered sinks with level `DebugLogLevel.critical`, `tag: 'PlatformDispatcher'`, `isUncaught: true`.
  - Internal capture wrapped in try/catch.
  - Returns `previous?.call(error, stack) ?? false` outside try/catch. Never returns `true` on its own.
- Safe restoration & pass-through (E-5, L-8):
  - When the last sink unregisters, if current handler is still our wrapper, restore previous handler.
  - If another component replaced or wrapped our handler, leave it in place and switch to pass-through.
- Replaced-handler detection (E-6):
  - Compares handler identities to detect if external libraries replaced handlers without chaining.
  - Exposes `ErrorHookStatus` enum: `off`, `active`, and `handlerReplaced` (`inactive (handler replaced)`).
- Pre-binding safety (E-7):
  - Uses static members only; verified safe before `WidgetsFlutterBinding.ensureInitialized()`.
- Public API integrity:
  - Preserves the ten-symbol export surface in `lib/debug_bubble.dart`.
  - Zero external dependencies; Flutter SDK only.
- Test coverage:
  - Focused tests for default off behavior, release inertness, chaining order, previous handler called once, previous handler throwing, null previous platform handler, restoration after dispose, replaced-handler detection, wrapped-by-another behavior, multi-controller sharing, repeated init, and pre-binding safety under `test/unit/hooks/`.

# T3.2 — Floating Draggable Bubble & Badge
Status: Implemented (Pending Consolidated Verification)
Phase / depends on: P3 / T3.1
Scope: Implementation of the floating draggable bubble widget (`FloatingBubble`) per UI_UX_SPEC.md §1.
Prerequisites: T3.1 (UI hosting overlay).
Expected file changes: `lib/src/ui/bubble.dart`, `doc/tasks/T3.2-draggable-bubble.md`, `test/widget/bubble_widget_test.dart`
Acceptance criteria:
- Renders as a 56 logical px circle with touch target >= 48 px.
- Initial positioning respects `config.initialBubbleAlignment` (default `Alignment.centerRight`).
- Supports free drag gestures bounded within safe area and keyboard insets (`MediaQuery.viewInsetsOf`).
- Snaps to the nearest horizontal edge (left or right) upon gesture release.
- Tap gesture triggers `controller.openDashboard()`.
- Error badge displays `controller.errorCount`:
  - Hidden when error count is 0.
  - Displays formatted count up to 99, and "99+" for counts > 99.
  - Decreases reactively when entries are evicted or cleared.
- Hidden when dashboard is open, or when controller is inactive/disposed/absent.
- Accessible semantic label: "Open debug dashboard" with error count included when present.
Relevant tests: `test/widget/bubble_widget_test.dart`

# T3.6 — Dashboard Actions
Status: Implemented (Pending Consolidated Verification)
Phase / depends on: P3 / T3.4, T2.7
Scope: Implementation of dashboard actions (Copy all, Export JSON, Clear all) with in-overlay feedback and dialog confirmation per UI_UX_SPEC.md §6 and DATA_MODELS.md §8, §9.
Prerequisites: T3.4 (logs & errors lists), T2.7 (filter matching & exporters).
Expected file changes: `lib/src/ui/actions.dart`, `lib/src/ui/dashboard.dart`, `doc/tasks/T3.6-dashboard-actions.md`, `test/widget/dashboard_actions_widget_test.dart`
Acceptance criteria:
- Top bar overflow menu exposes Copy all, Export JSON, and Clear all.
- "Copy all" exports plain text matching the current active filter (or all if none), enforcing the 500,000 char budget with oldest entries omitted messaging when exceeded.
- "Export JSON" produces Schema v1 JSON using `controller.exportJson(filter: filter)`.
- Clipboard copy (within 500k char cap) and `onExport` callback execute independently.
- If `onExport` throws an exception, the failure is caught and reported as "Export callback failed (ExceptionType)" without rethrowing or crashing.
- If clipboard fails, reported as "Copy failed".
- "Clear all" prompts with in-overlay confirmation dialog ("Clear all N entries? This cannot be undone.") and clears store on confirmation.
- Destructive clearing resets store, badge, and dropped counts.
- Zero reliance on host `Navigator`; all dialogs, menus, and feedback banners render within the dashboard overlay layer.
- Feedback banners are accessible via `Semantics(liveRegion: true)`.
- Back button precedence cleanly dismisses menu first, then confirmation dialog, then entry detail, then closes dashboard.
Relevant tests: `test/widget/dashboard_actions_widget_test.dart`

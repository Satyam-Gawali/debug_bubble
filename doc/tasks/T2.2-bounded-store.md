Acceptance criteria:

  - Bounded storage strictly respecting `maxEntries` (>= 1).
  - Oldest-first FIFO eviction when capacity is exceeded.
  - `droppedCount` increments only on capacity evictions (D-23 semantics).
  - `errorCount` accurately tracks stored entries where `level.isError`, incrementing on insertion, decrementing on eviction of an error entry, and resetting on `clear()`.

  - `clear()` empties stored entries and resets `droppedCount` and `errorCount` to 0. Monotonic IDs are maintained externally and not affected.
- DebugBubbleController:
  - Delegates `entries`, `entryCount`, `droppedCount`, and `errorCount` to the internal `DebugLogStore`.
  - Integrates `clear()` and `dispose()` with store reset.
  - Zero changes to the 10-symbol public API surface.
